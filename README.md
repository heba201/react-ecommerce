# E-Commerce Web Application (Frontend)
A modern, responsive full-featured e-commerce web application built with React.js/Next.js and Tailwind CSS. The application consumes secure RESTful APIs to provide a seamless shopping experience, from browsing products to secure checkout.

## 🚀 Features

* **User Authentication:** Secure Sign up, Sign in, and user profile management.
* **Address Book:** Manage shipping addresses with full CRUD functionality (View, Add, Edit, Delete).
* **Product Discovery:** Browse products with advanced search, category filtering, and brand filtering.
* **Shopping Cart & Wishlist:** Real-time cart and wishlist management with smooth state synchronization.
* **Checkout & Payments:** Flexible checkout supporting Cash on Delivery (COD) and online payment options.
* **Order Tracking:** Comprehensive order history dashboard to track past and current orders.

## 🛠️ Tech Stack

* **Framework:** React.js / Next.js
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **API Integration:** RESTful APIs (Axios / Fetch)
